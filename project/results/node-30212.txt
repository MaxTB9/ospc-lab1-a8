== 3. CPU efficiency = TotalCPU / (Elapsed x AllocCPUS) ==
TotalCPU = 30:37.751 = 1837.751 s
Elapsed  = 11:40     =  700 s
AllocCPUS = 32
Efficiency = 1837.751 / (700 x 32) = 1837.751 / 22400 = 0.082  (8.2 %)

This number is low because of how the job is built, not because workers were idle. The job runs
the worker counts one after another (1, 2, 4, 8, 16 workers, 5 repeats each) on the same 32
CPUs, so on average only 1837.751 / 700 = 2.6 CPUs are busy. Inside the runs the workers are
busy: per run, (anneal time + stream time) / (workers x compute wall time) is 0.99 for 1 worker
and 0.99 for 16 workers (from scaling-30212.csv). So the work is CPU-bound; the 8.2 % only says
the allocation (32 CPUs) is much bigger than what most of the runs use.

== 4. Real cores or hyperthreads? ==
Answer: pairs of hyperthreads. The 32 allocated CPUs are 16 physical cores with 2 hyperthreads each.

- lscpu: 2 threads per core, 512 CPUs = 256 physical cores.
- thread_siblings_list of CPU 21 is "21,277": CPU 21 and CPU 277 are the two hyperthreads of one core.
- The affinity 21-36,277-292 is exactly 16 such pairs: 21 with 277, 22 with 278, ... 36 with 292
  (each second number is the first plus 256, the pattern shown for CPU 21).
  The job got both hyperthreads of 16 cores, not 32 separate cores.

What it means for the plots:
- Up to 16 workers: the runner's own columns say pinned=1 and cores_used equals the worker count
  (1, 2, 4, 8, 16), so each worker had a physical core to itself. This is the clean part of the scaling plot.
- A 32-worker point on this same allocation would put two workers on each core (hyperthread
  siblings, sharing the core's execution units and caches), so it should not be read as 32 real
  cores. Expect clearly less than 2x the 16-worker speedup. If a job gets 64 CPUs (32 cores),
  workers up to 32 are on separate cores and only 64 workers use the hyperthreads.
- Other nodes may differ: the Jupyter node julia is an EPYC 9745, haskell is an EPYC 9755
  (same layout, 2 threads per core). Check lscpu and the affinity for each job.
