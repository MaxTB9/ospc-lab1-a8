== 4. Real cores or hyperthreads? ==
Answer: pairs of hyperthreads. The 64 allocated CPUs are 32 physical cores with 2 hyperthreads each.

- lscpu: 2 threads per core.
- thread_siblings_list of CPU 26 on fortran is "26,282": CPU 26 and CPU 282 are the two
  hyperthreads of one core.
- The affinity 26-57,282-313 is exactly 32 such pairs (26 with 282, 27 with 283, ... 57 with 313;
  each second number is the first plus 256).

How to read the scaling plot (from scaling-30974.csv, medians of 5 repeats):
- 1 to 32 workers: pinned=1 and cores_used equals the worker count, so every worker has a
  physical core to itself. Speedup 30.7 at 32 workers (efficiency 0.96). This is the clean part.
- 64 workers: cores_used stays 32. Two workers share each core (hyperthread siblings), so this
  point is not 64 real cores. Speedup 36.5, which is 19 % more than at 32 workers. Counting
  physical cores, 36.5 / 32 = 1.14: the second hyperthread on each core adds about 14 %.
  The efficiency 0.57 at 64 workers divides by 64 hyperthreads; divided by the 32 physical cores
  it is 1.14. Say which one is meant when quoting it.
